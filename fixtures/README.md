# Fixtures

`papers/<slug>/` holds a paper as `source.pdf`, `pages.json` (one entry per PDF page, see
`PagesFileSchema` in `packages/core`) and an approved `guide.yaml`. CLI chat, evals and tests read
them through the in-memory ports, without a database.

| Slug | What it is |
|---|---|
| `visible-cues` | Original **synthetic** paper (fictional study, data and references) written for UXie tests. Hand-written `pages.json` and guide; `source.pdf` is generated from them. Safe to commit. |
| `scanned-page` | Second synthetic paper (progress feedback in voice assistants) whose page 3 is figure-only, to test the `scanned_or_figure_only` warning. `pages.json` and `guide.yaml` were produced by `pnpm uxie ingest --local` with Sonnet 5.5; the guide awaits instructor review. |

The synthetic `source.pdf` files are generated by `pnpm --filter @uxie/ingest fixtures:pdf`
(deterministic: re-running produces identical bytes).

Do not commit copyrighted papers (PRD §13.5). To use a real paper locally, run
`pnpm uxie ingest path/to/paper.pdf --paper local-<name> --local`, which writes `source.pdf`,
`pages.json` and a draft `guide.yaml` into the git-ignored `fixtures/papers/local-<name>/`
(existing files are kept unless you pass `--force`). M4 adds an `injected` paper for the
prompt-injection eval.
